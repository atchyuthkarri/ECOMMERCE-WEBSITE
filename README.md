**Storely** is a full-stack MERN e-commerce platform with **secure authentication, admin dashboard, product CRUD operations**, and a **responsive React frontend**. Ideal for learning full-stack development, API optimization, and cloud deployment.

---

## 🚀 Features

<details>
<summary>Click to expand all features</summary>

- **User Authentication & Authorization**  
  JWT-based login/signup with role-based access for users and admins.

- **Product Management**  
  Admin dashboard to add, update, and remove products, manage inventory & categories.

- **Responsive & Optimized Frontend**  
  Built with React and Context API; reusable components reduce state bugs by **~40%**.

- **RESTful APIs**  
  20+ APIs built with Node.js & Express; optimized MongoDB queries improve response times by **~35%**.

- **Cart & Checkout**  
  Add/remove products, view totals, and prepare for checkout.

- **Deployment Ready**  
  Frontend hosted on **Vercel**, backend hosted on **Render**.

</details>

## ⚙️ Installation & Setup

**Clone the repository:**

```bash
git clone https://github.com/atchyuthkarri/ECOMMERCE-WEBSITE.git
cd ECOMMERCE-WEBSITE
```
## Backend Setup
```bash
cd backend
npm install
cp .env.example .env
# Update .env with MongoDB URI & JWT secret
npm start
```
## cd frontend
```bash
npm install
npm start
```
